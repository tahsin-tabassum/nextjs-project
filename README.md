# FitLog

FitLog is a modern workout library and planning app designed to help users discover exercises, create a daily workout plan, and save workouts for later. It provides detailed workout information including muscle groups, equipment, difficulty, sets, reps, duration, calories, and instructions.

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Context API
- Local Storage
- REST API
- Lucide React

## ✨ Key Features

1. **Workout Library**
   - Browse a collection of workouts covering different muscle groups.
   - View workout images, equipment, duration, calories, and ratings.

2. **Workout Details**
   - View detailed information about each workout.
   - Includes muscle groups, difficulty, sets, reps, calories, duration, rating, and step-by-step instructions.

3. **Daily Workout Plan**
   - Add workouts to today's plan.
   - Plan supports up to 5 exercises.
   - View total exercises, workout time, and estimated calories.

4. **Save Workouts for Later**
   - Save favorite workouts for quick access later.
   - Remove saved workouts whenever needed.

5. **Live Plan & Saved Counters**
   - Navbar counters update automatically when workouts are added or removed.
   - Toast notifications provide feedback when actions are completed.
